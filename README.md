# Squat Trainer Using Computer Vision

| **Project**       | **Description**                                                                                                                |
| ----------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| **Squat Trainer** | A computer vision project that uses pose estimation to analyze squat movements and provide feedback based on body positioning. |

## Objective

The objective of this project was to develop a computer vision-based system capable of tracking body movements during squats and analyzing posture using human pose estimation.

### Skills Learned

* Computer Vision
* Image and video processing
* Pose estimation
* Body landmark detection
* Real-time video analysis
* Python programming
* Movement analysis

### Tools Used

* **Python**
* **OpenCV**
* **MediaPipe**
* **NumPy**
* **Jupyter / VS Code**

## Steps

### 1. Video Input

A live camera feed or video input was captured for real-time movement analysis.

### 2. Pose Detection

A pose estimation framework was used to detect important body landmarks.

### 3. Landmark Extraction

Relevant body points such as the hip, knee, and ankle were identified for movement analysis.

### 4. Angle Calculation

Joint angles were calculated using detected body landmarks to understand the user's squat position.

### 5. Movement Analysis

The detected positions and angles were analyzed to identify different stages of the squat movement.

### 6. Feedback

The system was designed to provide feedback based on the detected body posture and movement.

### 7. Results & Insights

The project demonstrated how computer vision and pose estimation can be used to build practical fitness and movement-analysis applications.
